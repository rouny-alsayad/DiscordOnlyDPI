# DiscordOnlyDPI v0.9.3

> Discord-only connectivity helper for Windows — designed to keep games on their normal network path.

## ⬇️ Download

Download **`DiscordOnlyDPI-v0.9.3-windows-x64.exe`** from the Assets section below.

No installer is required. Run the EXE and keep it running while you use Discord.

## ✨ Highlights

- 🎯 **Discord-only routing** through a local SOCKS5 path.
- 🎮 **Game-safe design:** no system VPN, no Windows System Proxy, no route changes, no WinDivert, and no kernel network driver.
- 🔄 **Automatic Discord updates:** Discord Host and Modules are synchronized from Discord's official distribution manifest.
- 🔐 **SHA-256 verification** for downloaded Discord update packages.
- 🖥️ **Minimize to Tray** support.
- 🎨 Custom DiscordOnlyDPI icon for the EXE, taskbar, window, and tray.
- 📝 **One log file only:** `%LOCALAPPDATA%\DiscordOnlyDPI\last-run.log` always contains the latest run.
- 🦀 Native Rust build for Windows x64.

## 🚀 How to use

1. Download `DiscordOnlyDPI-v0.9.3-windows-x64.exe`.
2. Run it.
3. DiscordOnlyDPI checks Discord updates, prepares the required modules, and launches Discord.
4. Minimize DiscordOnlyDPI if you want it hidden in the Windows tray.
5. Keep DiscordOnlyDPI running while Discord is open.

## 🔎 Verify the download

Compare the EXE SHA-256 with the included `SHA256SUMS.txt` file.

PowerShell:

```powershell
Get-FileHash .\DiscordOnlyDPI-v0.9.3-windows-x64.exe -Algorithm SHA256
```

## ⚠️ Notes

- Windows 10/11 x64 is the current target.
- The current release is not code-signed, so Windows SmartScreen may show an unknown-publisher warning. Verify the SHA-256 before running it.
- Discord chat/UI traffic uses the local proxy path.
- Voice/WebRTC behavior can differ because WebRTC may use UDP outside ordinary SOCKS5 proxying. `--voice-tcp` remains experimental.
- The design avoids intentionally routing game traffic through DiscordOnlyDPI, but compatibility with every anti-cheat product cannot be guaranteed.
- This project is independent and is not affiliated with Discord or the ByeDPI project.

# العربية

> أداة اتصال خاصة بديسكورد على Windows، مصممة بحيث تبقى الألعاب على مسار الإنترنت العادي.

## ⬇️ التحميل

نزّل **`DiscordOnlyDPI-v0.9.3-windows-x64.exe`** من قسم **Assets** أسفل صفحة الـRelease.

لا تحتاج Installer. شغّل ملف الـEXE واترك البرنامج يعمل أثناء استخدام Discord.

## ✨ أهم الميزات

- 🎯 **Discord فقط** يمر عبر مسار SOCKS5 محلي.
- 🎮 **تصميم Game-Safe:** لا System VPN، لا Windows System Proxy، لا تغيير Routes، لا WinDivert، ولا Kernel Network Driver.
- 🔄 **تحديث Discord تلقائيًا:** البرنامج يزامن Discord Host وModules من الـmanifest الرسمي الخاص بديسكورد.
- 🔐 التحقق من **SHA-256** لحزم تحديث Discord التي يتم تنزيلها.
- 🖥️ دعم **Minimize to Tray**.
- 🎨 لوقو DiscordOnlyDPI لملف EXE والـTaskbar والنافذة والـTray.
- 📝 **ملف Log واحد فقط:** `%LOCALAPPDATA%\DiscordOnlyDPI\last-run.log` ويحتوي دائمًا على آخر تشغيل.
- 🦀 مبني بلغة Rust لـWindows x64.

## 🚀 طريقة الاستخدام

1. نزّل `DiscordOnlyDPI-v0.9.3-windows-x64.exe`.
2. شغّله.
3. البرنامج يفحص تحديثات Discord، يجهز الـModules المطلوبة، ثم يشغّل Discord.
4. إذا صغّرت DiscordOnlyDPI يختفي إلى سهم الـTray بجانب الساعة.
5. اترك DiscordOnlyDPI يعمل طالما Discord مفتوح.

## 🔎 التحقق من الملف

قارن SHA-256 للـEXE مع الملف `SHA256SUMS.txt` المرفق بالـRelease.

PowerShell:

```powershell
Get-FileHash .\DiscordOnlyDPI-v0.9.3-windows-x64.exe -Algorithm SHA256
```

## ⚠️ ملاحظات

- الهدف الحالي Windows 10/11 x64.
- النسخة الحالية غير موقعة بشهادة Code Signing، لذلك قد يظهر تحذير Unknown Publisher من Windows SmartScreen. تحقق من SHA-256 قبل التشغيل.
- واجهة Discord والـChat تعمل عبر مسار البروكسي المحلي.
- Voice/WebRTC قد يتصرف بشكل مختلف لأن WebRTC يمكن أن يستخدم UDP خارج SOCKS5 العادي. خيار `--voice-tcp` ما زال تجريبيًا.
- تصميم البرنامج لا يمرر ترافيك الألعاب عمدًا عبر DiscordOnlyDPI، لكن لا يمكن ضمان التوافق مع كل Anti-Cheat موجود.
- المشروع مستقل وغير تابع رسميًا لـDiscord أو مشروع ByeDPI.
