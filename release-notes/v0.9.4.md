# DiscordOnlyDPI v0.9.4

> Fix for Discord Host `1.0.9268`: Discord no longer starts with `Cannot find module 'discord_desktop_core'`.

## ⬇️ Download

Download **`DiscordOnlyDPI-v0.9.4-windows-x64.exe`** from the Assets section below.

No installer is required. Run the EXE and keep it running while you use Discord.

## 🐛 Fixes

- 🧩 **Discord Host `1.0.9268` support.** Newer Discord hosts removed the legacy module loader. With Discord's updater disabled, modules are now only loaded from `localModulesRoot` in `build_info.json`. DiscordOnlyDPI now writes that path, pointing at the modules it already downloads and verifies.
- 🖼️ Tray/window icon loading updated for the latest Rust toolchain checks.

## 🔁 Upgrading from v0.9.3

Just run v0.9.4. Nothing needs to be deleted or reinstalled: the already installed Discord host is patched on the first run.

If Discord still fails to start, share `%LOCALAPPDATA%\DiscordOnlyDPI\last-run.log`.

## 🔎 Verify the download

Compare the EXE SHA-256 with the included `SHA256SUMS.txt` file.

PowerShell:

```powershell
Get-FileHash .\DiscordOnlyDPI-v0.9.4-windows-x64.exe -Algorithm SHA256
```

# العربية

> إصلاح لإصدار Discord Host `1.0.9268`: ديسكورد ما عاد يطلع خطأ `Cannot find module 'discord_desktop_core'`.

## ⬇️ التحميل

نزّل **`DiscordOnlyDPI-v0.9.4-windows-x64.exe`** من قسم **Assets** أسفل صفحة الـRelease.

لا تحتاج Installer. شغّل ملف الـEXE واترك البرنامج يعمل أثناء استخدام Discord.

## 🐛 الإصلاحات

- 🧩 **دعم Discord Host `1.0.9268`.** إصدارات Discord الجديدة أزالت طريقة تحميل الـModules القديمة. لما يكون الـupdater معطّل، Discord صار يحمّل الـModules فقط من `localModulesRoot` داخل `build_info.json`. DiscordOnlyDPI صار يكتب هذا المسار ويوجّهه للـModules اللي ينزّلها ويتحقق منها.
- 🖼️ تحديث طريقة تحميل أيقونة الـTray والنافذة لتتوافق مع فحوصات Rust الأحدث.

## 🔁 الترقية من v0.9.3

شغّل v0.9.4 فقط. لا تحتاج تحذف أو تعيد تثبيت أي شيء: البرنامج يعدّل نسخة Discord المثبتة عند أول تشغيل.

إذا ما اشتغل Discord، شارك ملف `%LOCALAPPDATA%\DiscordOnlyDPI\last-run.log`.

## 🔎 التحقق من الملف

قارن SHA-256 للـEXE مع الملف `SHA256SUMS.txt` المرفق بالـRelease.

PowerShell:

```powershell
Get-FileHash .\DiscordOnlyDPI-v0.9.4-windows-x64.exe -Algorithm SHA256
```
