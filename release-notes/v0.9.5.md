# DiscordOnlyDPI v0.9.5

> DiscordOnlyDPI now updates itself from GitHub, Discord updates install in the background while Discord is open, and a Discord update that fails to start is rolled back automatically.

## ⬇️ Download

Download **`DiscordOnlyDPI-v0.9.5-windows-x64.exe`** from the Assets section below.

No installer is required. Run the EXE and keep it running while you use Discord.

## ✨ New

- 🔄 **Updates while Discord is open.** Every 30 minutes DiscordOnlyDPI checks Discord's official manifest. A new Discord version is downloaded and installed next to the running one without interrupting it.
- 🔔 **Restart when you choose.** When the update is ready, a Windows notification appears. Click it, or right-click the tray icon, to restart Discord with the update. If you ignore it, the update is used the next time DiscordOnlyDPI starts. Discord is never restarted without your click.
- ⬆️ **DiscordOnlyDPI updates itself.** On every start it checks the latest GitHub release. A newer version is downloaded, verified against `SHA256SUMS.txt`, swapped in place (same file name), and restarted before Discord opens. Any failure keeps the current version. Turn it off with `--no-self-update`. Future releases can normally install automatically while GitHub Releases and its checksum assets remain accessible.
- 🛟 **Automatic rollback.** DiscordOnlyDPI remembers the last Discord version that started correctly. If a new version fails to start (like the `Cannot find module 'discord_desktop_core'` error fixed in v0.9.4), it is closed, the last working version is started instead, and the broken version is skipped until Discord releases a newer one.
- 📝 Discord's own startup output is still written to `last-run.log`, together with the update and rollback decisions.
- 💬 **Clear error messages.** When Discord fails to start or DiscordOnlyDPI hits a fatal error, a bilingual Arabic/English dialog explains the problem. If a previously working Discord version is available, rollback is attempted; otherwise the dialog says no fallback exists. The app tries to save `error-report.txt` and opens File Explorer with the report selected after you press OK. Attach the report to a [GitHub issue](https://github.com/rouny-alsayad/DiscordOnlyDPI/issues). If report creation fails, the dialog points to `last-run.log`.

## 📁 New local files

```text
%LOCALAPPDATA%\DiscordOnlyDPI\state.json
%LOCALAPPDATA%\DiscordOnlyDPI\error-report.txt
```

- `state.json` stores the last working Discord version and its official manifest, so it can be restored.
- `error-report.txt` is created when a reported failure occurs. It copies the current `last-run.log`, but is not cleared at the next launch. Review it before posting publicly because diagnostic output can include local paths or network information.

## 🔎 Verify the download

Compare the EXE SHA-256 with the included `SHA256SUMS.txt` file.

PowerShell:

```powershell
Get-FileHash .\DiscordOnlyDPI-v0.9.5-windows-x64.exe -Algorithm SHA256
```

# العربية

> تحديثات Discord صارت تتنزّل بالخلفية وDiscord مفتوح، وإذا تحديث خرّب تشغيل Discord البرنامج بيرجع تلقائيًا لآخر نسخة شغالة.

## ⬇️ التحميل

نزّل **`DiscordOnlyDPI-v0.9.5-windows-x64.exe`** من قسم **Assets** أسفل صفحة الـRelease.

لا تحتاج Installer. شغّل ملف الـEXE واترك البرنامج يعمل أثناء استخدام Discord.

## ✨ الجديد

- 🔄 **التحديث وDiscord مفتوح.** كل 30 دقيقة البرنامج يفحص الـmanifest الرسمي. أي إصدار جديد يتنزّل ويتثبّت جنب النسخة الشغالة بدون ما يقطعها.
- 🔔 **إعادة التشغيل بوقت يناسبك.** لما يجهز التحديث يطلع إشعار من ويندوز. اضغط عليه، أو كليك يمين على أيقونة البرنامج بالـTray، ليعيد تشغيل Discord بالتحديث. إذا تجاهلته، التحديث بيشتغل بالمرة الجاية لما تفتح البرنامج. Discord ما بيتعاد تشغيله أبدًا بدون ضغطتك.
- ⬆️ **البرنامج بيحدّث حاله.** عند كل تشغيل بيفحص آخر Release على GitHub. النسخة الأحدث بتتنزّل، بتتفحص مع `SHA256SUMS.txt`، بتتبدّل مكان القديمة بنفس الاسم، وبيعيد تشغيل حاله قبل ما يفتح Discord. إذا صار أي خطأ بتكمل النسخة الحالية. لإيقافها استخدم `--no-self-update`. عادةً الإصدارات القادمة بتتثبت تلقائيًا طالما GitHub Releases وملفات التحقق متاحة.
- 🛟 **رجوع تلقائي.** البرنامج يتذكر آخر نسخة Discord اشتغلت صح. إذا نسخة جديدة فشلت بالتشغيل (مثل خطأ `Cannot find module 'discord_desktop_core'` اللي انصلح بـv0.9.4)، بيسكّرها ويشغّل آخر نسخة شغالة، وبيتجاهل النسخة الخربانة لحد ما ينزل إصدار أحدث.
- 📝 مخرجات Discord وقرارات التحديث والرجوع كلها بتنكتب بـ`last-run.log`.
- 💬 **رسائل خطأ واضحة.** إذا Discord ما اشتغل أو توقف DiscordOnlyDPI بسبب خطأ، تظهر رسالة بالعربي والإنجليزي تشرح المشكلة. إذا في إصدار Discord سابق معروف أنه يعمل، يحاول البرنامج الرجوع إليه؛ وإذا ما في، يخبرك بعدم وجود نسخة بديلة. يحاول حفظ `error-report.txt`، وبعد ضغط OK يفتح مستكشف الملفات مع تحديد التقرير. أرفقه في [بلاغ GitHub](https://github.com/rouny-alsayad/DiscordOnlyDPI/issues). إذا فشل إنشاء التقرير، الرسالة بتدلّك على `last-run.log`.

## 📁 ملفات محلية جديدة

```text
%LOCALAPPDATA%\DiscordOnlyDPI\state.json
%LOCALAPPDATA%\DiscordOnlyDPI\error-report.txt
```

- `state.json` فيه آخر نسخة Discord اشتغلت صح مع الـmanifest الرسمي تبعها، عشان يقدر يرجعها.
- `error-report.txt` بينحفظ عند وقوع خطأ يتم الإبلاغ عنه، وهو نسخة من `last-run.log` لكن ما بينمسح بالتشغيل التالي. راجع الملف قبل نشره علنًا لأنه ممكن يتضمن مسارات محلية أو معلومات شبكة.
